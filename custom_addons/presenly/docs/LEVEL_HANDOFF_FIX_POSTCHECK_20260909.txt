   hanya mengizinkan current_step_id.assigned_user_ids; setelah approve,
   presenly_can_approve/can_reject jadi False. Yang salah hanya visibilitas
   data (record rule) dan respons controller API setelah aksi (approver
   kehilangan ACL baca sehingga _serialize error).
3. Bug laten: presenly.permission._presenly_current_rule() dipanggil di
   _compute_ui_permissions tapi TIDAK pernah didefinisikan -> potensi
   AttributeError saat fallback approvers kosong.
