   namun baris leave yang sudah punya route (mis. Sick Time Off id 2 -> rule
   59 dari batch generate 2026-09-09) tampil sebagai "Already Routed" dan
   to_create_count=0 sehingga tombol Generate hilang; UX tidak menjelaskan.
C. Preview saat onchange browser memakai record NewId (belum disimpan) pada
   domain _scope_has_route -> "Domains don't support NewId" -> status baris
   salah (to_create walau sudah routed / sebaliknya).
D. Preview Order memakai start_sequence/sequence_step global (10, 20, ...)
   padahal generate sesungguhnya memakai auto-assign per scope (max+10):
   preview bisa menampilkan Order yang berbeda dari hasil create.
