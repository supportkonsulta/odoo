REQUEST
- Order approval (sequence) pada Approval Routes dibuat otomatis.
- Admin tidak perlu mengisi Order manual; step berikutnya otomatis mengambil
  Order berikutnya (+10) dalam scope yang sama.

APPROACH
- Order tetap tersimpan di presenly.approval.rule.sequence dan merupakan satu
  perintah urutan: step berjalan dari Order terkecil ke terbesar.
- Order diberikan otomatis saat create: max(current) + 10, mulai dari 10.
- Nilai eksplisit dari caller (test, API, resequence drag) selalu dihormati.
- Constraint unik scope (_check_unique_level_scope) tidak berubah: dua step
  tidak boleh memakai Order sama dalam company + work location + request type
  yang sama. Dengan auto-assign, konflik tersebut praktis tidak terjadi lagi
  untuk create baru via UI.
