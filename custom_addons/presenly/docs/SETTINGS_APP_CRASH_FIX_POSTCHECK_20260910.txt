PRESENLY SETTINGS APP CRASH FIX (OWL slots missing) — ROLLOUT POST-CHECK
Date: 2026-09-10
Database: odoo
Module: presenly 19.0.17.1.0

REPORT (production)
- Membuka menu Settings setelah upgrade memunculkan error:
  "Invalid props for component 'SettingsApp': 'slots' is missing
  (should be a object)."

ROOT CAUSE (dikonfirmasi dari source code Odoo 19)
1. addons/web/static/src/views/view_compiler.js — node dengan invisible="1"
   DI-DROP saat compile time (bukan runtime):
     if (!params.compileInvisibleNodes && (invisible === "True" || invisible === "1")) {
         return;
     }
2. Modul presenly menyembunyikan SEMUA block di <app name="hr_attendance">:
   - //block[@name='overtime_settings'] (invisible=1)
   - //block[@name='kiosk_mode_setting_container'] (invisible=1)
   - //block[.//field[@name='attendance_kiosk_url']] (invisible=1)
   -> <app> tanpa children.
3. SettingsFormCompiler.compileApp() memindahkan children app ke elemen
   SettingsApp; tanpa children, OWL tidak meng-generate prop slots.
4. addons/web/static/src/webclient/settings_form_view/settings/settings_app.js:
     static props = { string: String, imgurl: String, key: String,
                      selectedTab: {type: String, optional: 1},
                      slots: Object };   // Wajib, tidak optional
   -> OWL validator crash: "slots is missing".

FIX
- views/hr_attendance_integration_views.xml: tambah record
  res_config_settings_presenly_info — satu block SETIAP saat visible di dalam
  app hr_attendance:
    <block title="Managed by Presenly" name="presenly_managed_info">
        <setting string="Attendance and Kiosk settings are managed by Presenly"
                 help="Configure Work Locations, geofence, selfie policy,
                       Permission Types and Approval Routes under
                       Attendances > Configuration instead."/>
    </block>
  Diverifikasi dari source: SettingsBlock.props.slots optional; Setting.props
  semua optional (web.Setting template pakai guard t-if) -> block info valid
  dan selalu menghasilkan child -> SettingsApp.slots terisi -> halaman
  Settings render.
- UX bonus: admin melihat pesan penjelas alih-alih area kosong (App
  Attendances tetap muncul di daftar Settings).
- Version bump 19.0.17.0.0 -> 19.0.17.1.0.
