# Leaflet 1.9.4

Pustaka peta, disertakan apa adanya dari paket npm `leaflet`.

- Lisensi: BSD 2-Clause (lihat `LICENSE`), boleh disertakan ulang.
- Berkas: `leaflet.js`, `leaflet.css`, `images/`.
- Sumber: https://leafletjs.com

Sengaja **tidak** diambil dari CDN: Odoo yang dijalankan di jaringan tertutup
tetap harus bisa menampilkan peta ubinnya sendiri, dan versi yang disematkan
tidak berubah diam-diam saat CDN memperbarui berkasnya.
